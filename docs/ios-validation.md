# iOS 호환성 검증 — 2026-09-12

검사는 격리된 로컬 서버와 합성 데이터로 진행했습니다.

| 환경 | 확인 결과 |
| --- | --- |
| Playwright 1.63.0 / WebKit 26.6 (build 2359), iPhone SE 320px·iPhone 13 390px·iPad Mini 768px 프로필 | 15개 흐름 통과. macOS WebKit의 기기 에뮬레이션이며 실제 iOS 실행 결과는 아님. |
| Xcode 16.4 / iOS 18.5 (22F77), iPhone 16 Simulator Safari | 초기 로딩, 합성 데이터 표시, 가로 넘침 없음 확인. 입력 자동화가 모달을 열지 못했고 Simulator UI 제어도 `noWindowsAvailable`로 실패해 후속 입력 검증은 미완료. |
| 실제 iPhone·iPad | 연결된 기기가 없어 미검증. |

WebKit에서는 터치 저장·재조회·오류 재시도, 현지 날짜, 잔액 0, 계좌 종료·재개, USD 수정, 기간·작업 필터, 카테고리 이름 변경, JSON 백업·추가 복원, XLSX 미리보기·경고·중복 제외를 확인했습니다. 파일 검사는 브라우저 입력에 테스트 파일을 지정하는 방식으로, iOS Files 선택기를 검증하지 않습니다.

Safari에서 버튼을 터치하면 DOM 포커스가 버튼으로 이동하지 않아 모달 종료 시 원래 버튼으로 돌아가지 않는 문제를 수정했습니다. 공통 버튼 클릭 처리에서 모달이 열리기 전에 포커스를 지정합니다. 상세·삭제 모달의 포커스 복원과 키보드 순환을 회귀 검사에 포함했습니다.

재실행:

```sh
pnpm exec playwright install webkit # Linux에서는 --with-deps 추가
pnpm test:ios
```

실기기에서는 테스트 데이터로 다음 항목을 추가 확인해야 합니다.

- Safari 입력 시 키보드가 필드·저장 버튼을 가리지 않는지, 의도치 않은 확대가 생기지 않는지.
- 날짜·월 선택기와 세로·가로 회전 후 필터·모달의 접근 가능 여부.
- Files에서 JSON·XLSX 선택, 백업 다운로드와 복원 왕복.
- VoiceOver의 필드 이름, 오류 안내, 모달 진입·종료 후 읽기 위치.
